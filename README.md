# 发圈防折叠

一个无广告、无服务器、纯本地运行的原生微信小程序。它通过插入不可见 Unicode 分隔符和自然分段，尝试降低长文案被朋友圈折叠的概率。

> 微信的展示规则会随版本变化，任何工具都无法承诺 100% 不折叠。

## 直接运行

1. 打开微信开发者工具。
2. 选择「导入项目」，目录选择本文件夹。
3. 仅本地预览可使用测试号；需要在手机长期使用时，把 `project.config.json` 的 `appid` 换成你自己的小程序 AppID。
4. 点击「编译」，然后用真机预览测试复制效果。

项目没有网络请求、后端服务、登录、广告 SDK 或 npm 依赖。

## 三种模式

- 轻处理：每隔一段文字插入一个不可见的 `U+2060 WORD JOINER`，保留原排版。
- 自然分段：在标点附近给长段落增加空行。
- 加强处理：同时分段并增加不可见符号。

链接和邮箱会被保护，不会在地址内部插入符号。

## 发布给自己用

在微信公众平台注册个人小程序，取得 AppID 后替换项目配置中的 `touristappid`。上传代码并提交审核，通过后可发布。因为不使用服务器和敏感能力，通常不需要配置业务域名。

发布前还需要在小程序后台的「服务内容声明 → 用户隐私保护指引」中声明使用“剪贴板”，用途可填写：“仅在用户主动点击粘贴或复制时，读取或写入朋友圈文案；内容只在本地处理，不会上传。”否则正式版中的复制、粘贴接口会被微信拒绝。项目内已经实现了微信要求的隐私授权弹窗。

建议在描述里准确使用“文案排版”“减少折叠概率”等措辞，不要承诺“永久不折叠”或“100% 防折叠”。
